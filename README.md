# Almacenamiento-claude
Almacenamiento digital de trabajos 

## Agentes

- **abogado-familia** (`.claude/agents/abogado-familia.md`): especialista en Derecho de Familia, Niñez y Adolescencia del Ecuador (CNA y COGEP). En Claude Code, invócalo pidiendo, por ejemplo: "Usa el agente abogado-familia para redactar una demanda de alimentos".

## Plantillas

La carpeta [`plantillas/`](plantillas/README.md) contiene borradores de escritos de familia (alimentos, contestación, aumento, rebaja y extinción de pensión, tenencia, régimen de visitas, liquidación y apremio, divorcio y salida del país) que el agente usa como base.

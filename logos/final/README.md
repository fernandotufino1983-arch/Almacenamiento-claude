# Jurix Global — archivos finales del logo

Los SVG tienen el texto convertido a trazos: se ven igual en cualquier equipo y sirven para imprenta, bordado y señalética. Los PNG tienen fondo transparente.

| Archivo | Uso |
|---|---|
| `horizontal-color` | Uso principal sobre fondos claros: web, documentos, papelería, firmas de correo |
| `horizontal-negativo` | Sobre azul marino u oscuro: portada web, fachada, uniforme oscuro |
| `vertical-*` | Espacios cuadrados o altos: redes, carpetas, banners verticales, pantallas de inicio |
| `isotipo-*` | Solo el símbolo: sellos, bordado en pecho, marcas de agua, detalles |
| `*-negro` / `*-blanco` | Un solo color: fotocopias, fax, sellos de goma, grabado, bordado de un hilo |
| `avatar` | Foto de perfil de WhatsApp, Facebook, Instagram, LinkedIn |
| `favicon`, `favicon-180`, `favicon-32` | Ícono de la pestaña del navegador y del acceso directo en celulares |

## Colores

| Color | HEX | CMYK aprox. |
|---|---|---|
| Azul marino (principal) | `#0B1F3A` | 100 / 85 / 40 / 45 |
| Dorado (acento) | `#B8955A` | 25 / 40 / 70 / 5 |
| Marfil (fondo claro) | `#F7F4EE` | 2 / 3 / 6 / 0 |
| Negro carbón | `#1C1C1E` | 70 / 65 / 60 / 80 |

Tipografías (Google Fonts): **Cormorant Garamond 600** para el nombre y **Inter 400/500** para textos.

## Reglas básicas

- Deja alrededor del logo un margen libre al menos igual a la altura de la barra dorada multiplicada por 4.
- Tamaño mínimo: logo horizontal 35 mm (impreso) o 140 px (pantalla); isotipo 10 mm o 32 px.
- No cambies los colores, no estires ni deformes el logo, no le agregues sombras ni efectos.
- El dorado no se usa para textos sobre fondo claro.

# Normativa

Coloca aquí los textos legales vigentes (en `.md` o `.txt`, para que el agente
pueda buscarlos) que quieras que el agente `abogado-civil-ecuador` consulte
antes de citar. Por ejemplo:

- `codigo-civil.md`
- `cogep.md`
- `constitucion.md`
- `logjcc.md`
- `cofj.md`
- `codigo-de-comercio.md`

Indica en la primera línea de cada archivo la fecha de la última reforma
incorporada, para que el agente sepa qué tan actualizada está la versión.

Los PDF también pueden leerse, pero el texto plano permite búsquedas más
rápidas y precisas.
